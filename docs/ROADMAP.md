# ROADMAP — webpokerdealer

家庭德州扑克发牌助手。核心不变量：**牌堆与底牌只在服务器上，任何设备只收到它该看到的信息**。

## 目标

- 一台平板当"公牌桌"（桌子中间），显示公共牌 + 控制发牌进度
- 每人用自己手机扫码入座，只在手机上看自己的两张底牌
- 一个容器 Docker 部署到 NAS，局域网内手机/平板访问
- 不洗牌、不发牌、不记录筹码（筹码在实体桌上）

### M1 可玩 MVP —— ✅ 完成
- FastAPI + WebSocket 单进程：页面 / API / WS 一体，无前端构建
- 创建牌桌、扫码/输码入座、断线重连（前端指数退避）
- 公牌桌：公共牌、座位、开始本局 / 下一轮 / 重置 / 移出玩家
- 手机端：自己的底牌、公共牌、弃牌/取消弃牌
- 摊牌时只亮出未弃牌玩家的牌
- Docker 单容器（非 root + healthcheck）、docker-compose

## 已知限制

- 状态全在内存：容器重启 → 所有牌桌丢失（家庭娱乐可接受，见 `DECISIONS.md`）
- 无数据库、无账号体系、无持久化
- 公牌桌未鉴权（家庭局域网内使用）

## 覆盖率

不追求 100%。测试重点：
- 领域逻辑边界（发牌张数、盲注/按钮、街道推进、摊牌揭示规则）
- 安全不变量（底牌不泄露给公牌桌与其他玩家、token 校验）
