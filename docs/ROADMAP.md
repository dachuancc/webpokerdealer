# ROADMAP — webpokerdealer

家庭德州扑克发牌助手。核心不变量：**牌堆与底牌只在服务器上，任何设备只收到它该看到的信息**。

## 目标

- 一台平板当"公牌桌"（桌子中间），显示公共牌 + 控制发牌进度
- 每人用自己手机扫码入座，只在手机上看自己的两张底牌
- 一个容器 Docker 部署到 NAS，局域网内手机/平板访问
- 不洗牌、不发牌、不记录筹码（筹码在实体桌上）

## 已完成的问题修复

- **中途入座者被算进本局**（模糊测试拓出）：一局打到河牌后有人入座，他本局没被发牌，
  但 `_evaluate_showdown` 对「未弃牌」玩家一律求值，`best_hand([] + community)` 仍能
  从公共牌算出牌型 —— 于是这名旁观看可能被列为赢家（400 个随机种子中命中 10 次），
  历史里还会给他记下空底牌。已引入 `Player.in_hand`（`bool(hole)`，非空即“本局确实发了牌”），
  在比牌、亮牌、历史三处一并排除。回归测试见 `tests/test_table.py`。
- **摊牌时机**：之前翻牌/转牌就能点「摊牌」，不合理。现改为**只有河牌发完后**
  才能摊牌，服务端拒绝提前摊牌（`请先发完河牌再摊牌`）。
- **音效不响**：WebAudio 未在首个手势解锁 / 音量过小 / 只在公牌桌有音效。
  已改为：多种交互事件解锁 + 首次 `resume()` 后重试 + 提高音量，两端都可开音效，
  设置里加「试听音效」便于验证。
  另：iOS/Safari 仅 `resume()` 不够，需在手势里真正播放一次；已在首个手势播放
  静音 buffer 完成解锁（否则玩家端“试听”有声、服务器触发的发牌声无音）。
- **断线重连风暴**（`55f4016`）：客户端对着已失效牌桌无限重连。
  已改为「每次断开只调度一次重连」+ 致命错误（`table_missing` / `bad_token`）停止重连。
  `DECISIONS.md` D10。

## 已知限制

- 状态全在内存：容器重启 → 所有牌桌丢失（家庭娱乐可接受，见 `DECISIONS.md`）
- 无数据库、无账号体系、无持久化
- 公牌桌已有主持人 PIN 鉴权（D12）；玩家入座无需密码
