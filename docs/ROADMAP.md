# ROADMAP — webpokerdealer

家庭德州扑克发牌助手。核心不变量：**牌堆与底牌只在服务器上，任何设备只收到它该看到的信息**。

## 目标

- 一台平板当"公牌桌"（桌子中间），显示公共牌 + 控制发牌进度
- 每人用自己手机扫码入座，只在手机上看自己的两张底牌
- 一个容器 Docker 部署到 NAS，局域网内手机/平板访问
- 不洗牌、不发牌、不记录筹码（筹码在实体桌上）

## 已完成的问题修复

- **音效不响**：WebAudio 未在首个手势解锁 / 音量过小 / 只在公牌桌有音效。
  已改为：多种交互事件解锁 + 首次 `resume()` 后重试 + 提高音量，两端都可开音效，
  设置里加「试听音效」便于验证。
- **断线重连风暴**（`55f4016`）：客户端对着已失效牌桌无限重连。
  已改为「每次断开只调度一次重连」+ 致命错误（`table_missing` / `bad_token`）停止重连。
  `DECISIONS.md` D10。

## 已知限制

- 状态全在内存：容器重启 → 所有牌桌丢失（家庭娱乐可接受，见 `DECISIONS.md`）
- 无数据库、无账号体系、无持久化
- 公牌桌未鉴权（家庭局域网内使用）
