# Vector Playing Cards — 来源与许可

- 来源：[notpeter/Vector-Playing-Cards](https://github.com/notpeter/Vector-Playing-Cards)，
  原始作者 **Byron Knoll**（[vector-playing-cards](https://code.google.com/p/vector-playing-cards/)）。
- **许可：公有领域（Public Domain）；在公有领域不被承认的地区可选 WTFPL。**
  可自由使用、修改、再分发（含商业用途）。
- 本目录为原 SVG 副本，仅做了：去掉 XML 注释与 `<metadata>`、按本项目约定重命名。
- 命名：`<点数><花色>.svg`，点数 `2-9 / T / J / Q / K / A`，花色 `s/h/d/c`
  （例如 `As.svg` = 黑桃 A，`Tc.svg` = 梅花 10）。Joker 未收录。
- 该套牌**不含牌背**，程序会使用内置的 CSS 牌背（可在「外观 → 牌背」换色）。
