# GreyWyvern Playing Card Set — 来源与许可

- 来源：[OpenGameArt · GreyWyvern Playing Card Set](https://opengameart.org/content/greywyvern-playing-card-set)
  （作者 GreyWyvern，www.greywyvern.com）。
- **许可：公有领域（Public Domain）**；在公有领域不适用时可用 **BSD 2-clause**。
  作者原话："These cards are released by me into the public domain."
  完整 BSD 文本见原压缩包内的 `licence.txt`。
- 本目录为转换产物：由原 **SVG** 用 `cairosvg` 渲染为 **300px 宽 PNG**（控制体积）。
- 命名：`<点数><花色>.png`，点数 `A/2-9/T/J/Q/K`（`T`=10），花色 `s/h/d/c`
  （例如 `As.png` = 黑桃 A，`Td.png` = 方块 10）。
- 另含 13 种牌背 `back1.png … backd.png`；默认使用 `backb.png`（蓝色），
  可在 `decks.json` 里把该牌组的 `back` 改成别的。
