# 图片牌组（可选）

默认牌面是内置的 CSS 画法（白色牌 + 点数/花色）。想换成**绘图牌面**，把一套牌
放进本目录，然后在 `decks.json` 里登记，就能在公牌桌/玩家端的
「⚙️ → 外观 → 牌面样式」里选择。

## 1. 文件命名

每张牌一个文件，文件名 = **点数 + 花色**：

- 点数：`2 3 4 5 6 7 8 9 T J Q K A`（`T` 表示 10）
- 花色：`s`（黑桃）`h`（红心）`d`（方块）`c`（梅花）

例如：`As.png`（黑桃 A）、`Td.png`（方块 10）、`7c.png`（梅花 7）。
牌背命名为 `back.png`（名字可在 `decks.json` 里用 `back` 改）。

一共 52 + 1 个文件。支持浏览器能显示的格式（png / svg / webp / jpg）。

## 2. 目录结构示例

```
static/cards/
├── decks.json
└── mydeck/
    ├── 2s.png … As.png（共 52 张）
    └── back.png
```

## 3. 在 decks.json 里登记

```json
[
  { "id": "mydeck", "name": "我的牌面", "dir": "/static/cards/mydeck/", "ext": ".png" }
]
```

- `id`：唯一标识（存进 localStorage）。
- `name`：设置里下拉框显示的名字。
- `dir`：牌组目录（以 `/` 结尾，从站点根开始）。
- `ext`：文件扩展名（含点）。
- `back`：可选，牌背文件名，默认 `back.svg`。

改完 **重启服务**（静态资源版本哈希在启动时计算），然后在设置里选即可。

  下载时把对应的许可证文件（如 `LICENSE`）一并放进牌组目录，方便日后追溯。
