# 音效文件

公牌桌与玩家端在**发牌 / 翻牌 / 摊牌**时会播放音效。默认用 WebAudio 合成（无需任何文件）。

想换成真实录音，只要把文件放进本目录，命名为下面三个之一即可；**缺哪个就用合成声兜底**，
所以可以只替换其中一个：

| 文件名 | 触发时机 | 建议时长 |
|---|---|---|
| `deal.mp3` | 发底牌（新一局开始） | 30–120ms |
| `flip.mp3` | 翻公共牌（翻牌/转牌/河牌） | 30–120ms |
| `reveal.mp3` | 摊牌亮牌 | 100–400ms |

说明：

- 支持浏览器能解码的格式；文件名固定为 `.mp3`。若想用其他格式/后缀，改
  `src/webpokerdealer/static/js/common.js` 里 `SAMPLE_FILES` 的路径即可。
- 音频越短越好：这是一次点击式的反馈音，太长会拖沓。
- 请使用自己录制或可商用免版税的素材。
- 改动后需**重启服务**（静态资源版本哈希在启动时计算），浏览器会自动加载新代码。
